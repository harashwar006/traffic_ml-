================================================================================
TRAFFICTWIN — HOW TO RUN BACKEND & FRONTEND
================================================================================

1. PREREQUISITES
----------------
- Python 3.10+ with CUDA/PyTorch installed
- Node.js v18+ and npm installed

--------------------------------------------------------------------------------
2. RUNNING THE BACKEND (FastAPI ML Server)
--------------------------------------------------------------------------------
Open a terminal in the project directory:

  cd d:\openhack\traffic_ml
  python -m uvicorn api.server:app --host 127.0.0.1 --port 8000 --reload

The backend will start at:
  -> http://127.0.0.1:8000
  -> Interactive Swagger API Docs: http://127.0.0.1:8000/docs
  -> Health check: http://127.0.0.1:8000/health

--------------------------------------------------------------------------------
3. RUNNING THE FRONTEND (Vite + React UI)
--------------------------------------------------------------------------------
Open a second terminal window:

  cd d:\openhack\traffic_ml\web
  npm install        (only needed the first time)
  npm run dev

The web app will open at:
  -> http://127.0.0.1:5173/

--------------------------------------------------------------------------------
4. RUNNING OFFLINE ML PIPELINE DIRECTLY (CLI Mode)
--------------------------------------------------------------------------------
To run detection, tracking, counting and evaluation directly via Python:

  cd d:\openhack\traffic_ml
  python main.py --video "D:/openhack/AIC21_Track1_Vehicle_Counting/Dataset_A/cam_5.mp4" --camera cam_5 --gt "D:/openhack/AIC21_Track1_Vehicle_Counting/counting_gt_sample/counting_example_cam_5_1min.csv" --max-frames 600

Output metrics will be saved in:
  - d:\openhack\traffic_ml\outputs\metrics\
  - d:\openhack\traffic_ml\outputs\videos\
================================================================================
